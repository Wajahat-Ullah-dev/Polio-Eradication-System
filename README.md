# Polio Eradication System 🩺

A web-based system to manage and track polio vaccination campaigns in Pakistan.

## 📌 About The Project
Pakistan میں polio کو ختم کرنے کے لیے health departments کو data manage کرنے میں مشکل ہوتی ہے۔ 
یہ system teams, children records اور campaigns کو digital طریقے سے track کرنے میں مدد دیتا ہے۔

یہ project میرے FYP کا حصہ ہے۔

## ✨ Key Features
- *User Roles*: Admin اور Field Worker کے لیے الگ login
- *Team Management*: Vaccinator teams اور ان کے areas assign کرنا
- *Child Registration*: 5 سال سے کم عمر بچوں کا ریکارڈ
- *Campaign Tracking*: ہر campaign کی coverage report
- *Dashboard*: Total vaccinated, missed اور refused بچوں کا summary
- *Reports*: Excel/PDF میں report export کرنا

## 🛠️ Technologies Used
- *Backend*: ASP.NET Core MVC, C#
- *Database*: SQLite
- *Frontend*: HTML5, CSS3, Bootstrap 5, JavaScript
- *IDE*: Visual Studio 2022

## 🚀 How to Run Locally
1. Clone the repository
```bash
   git clone https://github.com/Wajahat-Ullah-dev/Polio-Eradication-System.git
```

2. Open PolioEradication.sln in Visual Studio 2022

3. Press Ctrl + F5 to run the project

4. Database app.db خود بن جائے گی
