# Polio Eradication System

A web-based system to track and manage polio vaccination campaigns and data.

## 📌 About The Project
This system is developed as part of my FYP. It helps health departments to:
- Manage vaccination teams and areas
- Track children vaccination records
- Generate reports for campaigns
- Monitor coverage and missed children

## 🛠️ Built With
- *Framework*: ASP.NET Core MVC
- *Database*: SQLite / SQL Server
- *Frontend*: HTML, CSS, Bootstrap, JavaScript
- *IDE*: Visual Studio 2022

## 🚀 How to Run This Project
1. Clone the repository
   git clone https://github.com/Wajahat-Ullah-dev/Polio-Eradication-System.git
2. Open PolioEradication.sln in Visual Studio
3. Update database connection in appsettings.json if needed
4. Run the project Ctrl + F5
